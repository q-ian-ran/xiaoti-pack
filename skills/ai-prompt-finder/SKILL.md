# 万用 AI 提示词查找与定制

职责：为用户找到"现在就能复制使用"的 AI 提示词 —— 先弄清需求，再查本地库 / 联网搜集，最后定制改写并交付。

## 何时使用

- 用户想要某个场景的提示词或模板（写作、办公、编程、学习、数据分析、AI 绘画等）
- 用户说"不知道怎么问 AI""帮我写个提示词""有没有 XX 的提示词"
- 用户发来一段提示词，请点评或改进
- 用户索要"万能提示词""提示词大全"

## 工作流程

### 第 1 步：明确需求（最多问 3 个问题；能推断的不问）

需要知道的关键信息（缺什么问什么）：
1. 让 AI 做什么（任务目标）
2. 用在哪个平台（对话型 AI 还是绘画类 AI —— 决定提示词写法）
3. 场景细节（受众、篇幅、风格、必须包含或避免的内容）

用户描述已经足够具体 → 直接从第 2 步开始。

### 第 2 步：检索提示词

1. 先读 `references/prompt-library.md`，按开头的"需求 → 分类索引"定位最接近的模板
2. 库中没有合适模板 → 按 `references/sources.md` 的策略联网检索
3. 搜到素材后用 WebFetch 抓取并提取提示词原文；不要凭记忆编造"网上有"

### 第 3 步：定制改写（核心步骤，不可跳过）

- 按万能公式改造：**角色 + 背景 + 任务 + 要求 + 输出格式**
- 把所有 [占位符] 替换为用户真实信息；没提供的保留 `____` 并注明需要补充
- 按目标平台微调：对话型 AI 用自然语言表述；绘画类 AI 用「主体 + 细节 + 风格 + 参数」标签式写法
- 交付 1 条主提示词（最贴合）+ 最多 2 条备选变体（换风格 / 换侧重 / 更简洁）

### 第 4 步：按固定格式输出

【提示词】——代码块呈现，可直接复制，占位符清晰
【使用说明】——把提示词发给 AI 后还需要补充什么、如何追问
【微调建议】——2~3 条按需调整方向（更长/更短、换语气、加约束……）

## 输出规范

- 提示词必须自包含：拿走的人不看对话也能直接用
- 不把网络原文直接丢给用户，必须结合用户场景改写
- 用户需求太模糊（如"给我个万能提示词"）时：先给"万能兜底模板"（提示词库第 0 节），再引导用户补充具体场景
- 输出语言跟随用户

## 质量自查（交付前逐项检查）

- [ ] 角色 / 任务 / 要求 / 输出格式是否齐全？
- [ ] 占位符是否标注清楚、无遗漏？
- [ ] 是否适配用户指定的使用平台？
- [ ] 提示词本体是否纯净（没有多余的寒暄或解释混进去，复制即用）？

## 示例

用户："帮我写个周报提示词。"
处理：先问 1-2 个关键点（汇报对象？有无量化数据？）→ 匹配库中「2.1 周报生成」→ 替换占位符 → 按第 4 步格式输出。

## 持续积累

每次联网搜集到好用的新模板，按分类追加进 `references/prompt-library.md`，标注来源与日期 —— 让本地库越用越厚。
