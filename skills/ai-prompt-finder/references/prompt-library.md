## 0. 万能公式与兜底模板

### 0.1 万能公式（任何场景都能套）

**核心五要素：角色 + 背景 + 任务 + 要求 + 输出格式**

一句话版：
> 你是一名【角色】，请帮我【任务】。背景：【背景】。要求：【字数/风格/受众/禁忌】。请按【格式】输出。

五套经典框架速查（挑一个顺手的用）：

| 框架 | 构成 | 最适合 |
|---|---|---|
| RTF | 角色 + 任务 + 格式 | 日常快任务（改文、写函数、生成 SQL） |
| CO-STAR | 背景 + 目标 + 风格 + 语气 + 受众 + 输出 | 内容创作、营销文案（受众感强） |
| CRISPE | 角色 + 洞察 + 任务 + 个性 + 多方案实验 | 技术决策、要多个方案对比 |
| BROKE | 背景 + 角色 + 目标 + 关键结果 + 迭代 | 方案策划、项目管理 |
| LangGPT | 模块化：角色/技能/规则/流程/初始化 | 要反复用的提示词、智能体配置 |

### 0.2 万能兜底提示词（用户需求模糊时直接给）

```
你是一位世界级的任务执行专家。我想完成的事情是：【____】。
在开始前，如果你认为缺少必要信息，请先向我提出最多 3 个关键问题；
信息齐了之后，请输出：
1) 任务拆解（把大事拆成可执行的小步）
2) 逐步执行方案（每步注明输入、动作、输出）
3) 最容易踩的坑与规避方法
4) 直接给出最终结果
全部用大白话，不要客套话。
```

## 1. 写作与内容创作

### 1.1 通用写文章
```
你是一位【领域】资深作者，擅长写给【受众】看的内容。
请围绕主题【主题】写一篇【体裁：公众号文章/知乎回答/演讲稿】，要求：
- 字数：【800-1500 字】
- 风格：【通俗易懂像朋友聊天 / 专业严谨】
- 结构：开头用【痛点/故事/问题】引入，正文分 3 个要点，结尾给可执行建议
- 必须包含至少 1 个具体案例，不要空话套话
输出 Markdown 格式，带小标题。写完后用一句话说明你的创作思路，方便我提出修改。
```

### 1.2 小红书爆款笔记
```
你是拥有 5 年经验的小红书爆款笔记写手，擅长【赛道：美妆/学习/职场/生活】内容。
请围绕【主题】写一篇小红书笔记，要求：
- 面向【人群】，语气像闺蜜分享，口语化、不端着
- 正文 300-500 字，多用短句和换行，适当加 emoji
- 开头 2 行要有钩子（制造好奇或共鸣），结尾引导互动
- 给出 10 个爆款标题候选（带数字、有悬念、不夸张）
- 附 5 个话题标签
输出格式：标题候选 → 正文 → 标签，分段清晰。
```

### 1.3 短视频口播脚本
```
你是一位百万粉短视频编导。请为【主题】写一条【30 秒/60 秒】口播脚本，要求：
- 前 3 秒必须有钩子（提问/反常识/利益点）
- 正文口语化，每句话不超过 20 字，方便直接念
- 结构：钩子 → 痛点共鸣 → 3 个干货点 → 结尾引导关注
- 标注【画面提示】（配什么画面/字幕）
输出格式：分列"口播文案 / 画面提示"两栏。
```

### 1.4 批量标题生成
```
你是一位专业标题策划师。请为以下内容写 15 个标题：
内容主题：【____】
目标平台：【公众号/小红书/短视频/论文】
要求：
- 风格：【带数字/有悬念/有情绪/专业感】
- 长度不超过【20】字
- 不夸张标题党，但要有打开欲
输出格式：编号列表，每个标题后用括号标注它用了什么技巧。
```

## 2. 职场办公

### 2.1 周报 / 日报生成
```
你是一位资深职场写作顾问，擅长把零散的工作记录提炼成结构清晰、结果导向的周报。

我的本周信息：
- 本周完成事项：【____】
- 关键数据 / 成果：【____】（没有数据就写"帮我用定性方式描述"）
- 遇到的问题与风险：【____】
- 下周计划：【____】
- 汇报对象：【直属领导 / 部门群 / 公司大群】

要求：
1. 按「本周成果 / 问题与风险 / 下周计划」三部分组织
2. 成果用动词开头，尽量量化（完成度、节省时间、产出数量）
3. 问题部分写成「现象 + 我的应对 + 需要的支持」
4. 语气简洁专业，不写空话套话，总长不超过 500 字
5. 输出 Markdown，可直接粘贴到工作群

如果信息有缺漏，先列出你的疑问让我补充，再动笔。
```

### 2.2 PPT 大纲生成
```
你是一位专业演示文稿策划师，擅长【领域】主题的汇报。
请为题目【____】生成一份【N】页的 PPT 大纲，场景是【课堂展示/工作汇报/商业路演】，汇报对象是【受众】。
要求：
- 每页给出：页码、标题、核心要点（3 条内）、推荐配图/图表类型
- 整体逻辑：问题引入 → 核心论点 → 数据支撑 → 结论与行动建议
- 第 1 页封面，第 2 页目录，最后一页总结
- 语言精炼，每页要点不超过 30 字
输出格式：Markdown 表格（页码｜标题｜要点｜配图建议）。
```

### 2.3 会议纪要整理
```
你是专业会议记录整理专员。请把以下会议原始内容整理成结构化纪要：
【粘贴会议记录 / 转写文本】
要求：
- 提炼：会议议题、各方关键观点、达成的决策、待办事项
- 剔除寒暄与重复内容，客观中立，不添加个人评价
- 待办事项必须标注：事项、负责人、截止时间（没提到就写"待确认"）
输出格式：分「议题回顾 / 关键讨论 / 决议 / 待办清单」四部分，待办用表格。
```

### 2.4 高情商邮件 / 消息
```
你是一位高情商职场沟通专家。请帮我回复以下消息/邮件：
【原文粘贴】
我的目的：【同意/拒绝/催进度/道歉/提要求】
对方身份：【领导/同事/客户/老师】
要求：
- 先给 2 个版本：正式版（邮件用）和轻松版（微信/钉钉用）
- 态度得体：拒绝时给"替代方案"，催进度时给"台阶"
- 不超过 200 字，不卑不亢
输出格式：两版本分列 + 一句话说明各自适合的场景。
```

### 2.5 简历优化 + 面试预测
```
你是一位资深 HR / 面试官，熟悉【行业/岗位】的招聘标准。
请根据我的简历【粘贴简历或经历】，完成两件事：
1. 按 STAR 法则重写我的核心经历，突出量化成果（提升 X%、节省 X 小时）
2. 站在面试官角度，预测 10 个最可能被问到的问题，按可能性排序，每个附"考察点 + 参考答案要点"
如果我的简历有明显硬伤（空窗期/频繁跳槽），额外给出 3 条应对话术。
输出格式：修改后的简历段落 + 问题清单表格。
```

## 3. 编程开发

### 3.1 需求 → 代码
```
你是一位资深【语言/技术栈】工程师。请帮我实现以下需求：
【需求描述】
要求：
1. 先列出实现思路（3-5 步）
2. 代码可运行、有注释、处理边界情况（空值/异常/超长输入）
3. 给出 2-3 个测试用例，说明预期输出
4. 最后说明这段代码的性能注意点和可扩展方向
输出格式：思路 → 代码（代码块）→ 测试用例 → 注意事项。
```

### 3.2 报错排查
```
你是一位擅长排查疑难杂症的资深工程师。我的程序报错了：
- 报错信息：【粘贴完整报错】
- 相关代码：【粘贴代码】
- 环境：【语言版本 / 框架 / 操作系统】
请：
1. 先用大白话解释报错信息的含义
2. 列出最可能的 3 个原因，按可能性从高到低排序
3. 每个原因给出：如何验证 + 修复方案（具体到代码改动）
4. 如果信息不足，先告诉我需要补充什么
不要一次性瞎猜，按排查顺序来。
```

### 3.3 代码解释（小白向）
```
你是一位善于把复杂技术讲简单的编程导师。请解释以下代码：
【粘贴代码】
要求：
1. 先用一句话说明"这段代码是干什么的"
2. 逐段解释逻辑，每段用"它在做什么 + 为什么这么写"
3. 标注涉及的编程概念（如闭包、装饰器），并用生活比喻解释
4. 最后指出可能的坑或改进空间
面向【零基础/有 1 年经验】的读者，不要跳步。
```

### 3.4 代码评审 / 重构
```
你是一位严格的高级代码审查员，不客套，直接指出问题。
请审查以下代码：
【粘贴代码】
按以下维度检查：
1. Bug 和边界情况（最高优先）
2. 性能问题
3. 可读性与命名
4. 安全隐患（如注入、越权）
每个问题给出：严重程度（高/中/低）+ 为什么是问题 + 具体修复建议。
最后给出重构后的完整代码（如有必要）。
```

## 4. 学习与备考

### 4.1 费曼式讲解
```
你是一位擅长费曼学习法的老师。请用费曼技巧给我讲透【概念】：
1. 先用一句话说人话地解释它是什么（假设我 10 岁）
2. 用一个生活比喻展开讲清楚
3. 讲它的核心原理（由浅入深，分 2-3 层）
4. 指出初学者最容易搞混的 3 个点
5. 出 3 道小题检验我是否真的懂了（附答案）
如果哪个部分你只能靠术语解释，先停下来换个说法。
```

### 4.2 知识框架梳理
```
你是一位知识管理专家。请帮我把【学科/主题】梳理成一张知识框架：
- 先给顶层分类（3-6 个大模块）
- 每个模块再拆子知识点（一层即可，标注重点⭐）
- 标注知识点之间的依赖关系（先学什么、后学什么）
- 最后给我一个【7 天 / 30 天】的入门学习路线（每天学什么、花多久）
输出格式：Markdown 层级列表 + 路线表格。
```

### 4.3 出题自测
```
你是一位【科目】资深命题老师。请根据以下内容出题考我：
【粘贴知识点 / 笔记 / 章节】
要求：
- 出 10 道题：5 道选择题（4 选项）、3 道简答题、2 道应用题
- 难度分布：基础 6 道、进阶 3 道、拔高 1 道
- 先只给我题目，等我说"公布答案"再给答案和逐题解析
- 解析要说明考点，以及我做错可能的原因
```

### 4.4 错题诊断
```
你是一位耐心的学习教练。以下是我做错的题：
【题目 + 我的错误答案 + 正确答案】
请帮我：
1. 诊断我这道题错在哪一步（概念不清？审题失误？计算错误？）
2. 追溯这个错误背后的知识点漏洞
3. 用一句话讲清正确思路
4. 出 2 道同类型变式题巩固（附答案）
最后告诉我：这个漏洞如果不管，后续还会在哪些题型上继续丢分。
```

## 5. 数据分析

### 5.1 分析思路设计
```
你是一位资深数据分析师。我拿到了一份【描述数据：多少行、哪些字段、业务背景】，目标是【分析目的】。
请先不要急着分析，而是：
1. 列出你认为值得分析的角度（按价值排序）
2. 每个角度：需要用到哪些字段、做什么处理
3. 指出这份数据可能存在的坑（缺失值、口径问题、幸存者偏差等）
4. 给出一个完整的分析计划（步骤 + 每步产出）
等我确认后再逐步执行。
```

### 5.2 Excel 公式助手
```
你是一位 Excel 函数高手。我的需求：【描述想实现的效果】；数据情况：【哪些列、大概长什么样，可举例】。
请：
1. 给出可直接使用的公式（适配版本：【Excel 2016/365/WPS】）
2. 逐段拆解公式，解释每个函数在干嘛
3. 如果公式用不了，给替代方案（如辅助列分步实现）
4. 提醒容易出错的点（绝对引用、区域格式等）
```

### 5.3 SQL 生成与解释
```
你是一位资深数据仓库工程师。请帮我写一条 SQL：
- 目标：【描述查询需求】
- 表结构：【粘贴相关表和字段】
- 数据库：【MySQL/PostgreSQL/Hive 等】
要求：
1. 给出 SQL，加注释
2. 逐段解释逻辑
3. 提示性能注意点（索引、数据量、join 方式）
4. 给出简化版和完整版（含边界处理：去重、空值）
```

### 5.4 数据分析报告
```
你是一位咨询公司的高级分析师。以下是分析结果/数据：
【粘贴数据或结论】
请把它写成一份给【领导/客户】看的数据分析报告，要求：
1. 结构：结论先行 → 3 个核心发现（每个配数据支撑）→ 原因分析 → 行动建议
2. 语言：结论用大白话，专业术语后括号注白话解释
3. 每个建议可落地：谁、做什么、预期效果
4. 指出数据本身的局限性（样本、口径）
输出 Markdown，标题层级清晰，可直接放进周报/PPT。
```

## 6. AI 绘画与视频

### 6.1 描述 → 绘画提示词

你是一位专业的 AI 绘画提示词工程师。我想画：【用大白话描述想画的内容】。
请生成 3 个版本的绘画提示词：
1. 中文详细版（适合即梦、可灵、文心一格等国产平台）

每个版本包含：主体 + 环境 + 光影 + 构图视角 + 风格 + 质量词。
最后告诉我：想调整【色调/氛围/风格】时，应该改哪个词。

逐镜头列出：
- 镜头号 / 时长

- 台词或字幕文案

整体节奏：前 3 秒抓眼球，中段信息密度高，结尾留记忆点。
输出格式：表格。

## 7. 生活与决策

### 7.1 旅行行程规划
```
你是一位本地深度游规划师。请帮我规划【城市】的【3 天 2 晚】行程：
- 同行人：【独自/情侣/带父母/带娃】
- 预算：【人均 X 元，不含大交通】
- 偏好：【美食优先/历史人文/自然风光/轻松不赶】

### 8.1 提示词生成器
```
你是一位世界级的提示词工程师（熟悉 CO-STAR、LangGPT 等框架）。

## 9. 使用技巧（提升效果的小招）

- **先框架后细节**：第一轮先让 AI 列大纲/思路，确认后再让它写完整版
- **迭代口令**："请按 0-10 分自评这段输出，指出扣分项，然后重写到 9 分"
- **追问三连**："详细展开第 2 点" / "举一个具体例子" / "用表格重新整理"
- **控制风格**："保持简洁，删掉所有客套话" / "每段不超过 3 句"
- **给例子胜过给描述**（少样本提示）：贴一个你喜欢的样例，说"照这个风格来"
- **长任务分开问**：一次只解决一个环节，上下文更干净
- **让 AI 反问你**：结尾加一句"开始前，若缺信息请先向我提问"，能大幅减少方向跑偏
